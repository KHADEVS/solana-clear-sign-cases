# Anchor IDLs

Programs that publish an Anchor IDL and no Codama IDL. `source/` holds the IDL as the program publishes it on chain (the Anchor IDL account, zlib-inflated); the file next to it is the same IDL converted by Codama's own converter (`node tools/codama/from-anchor.mjs`, `@codama/nodes-from-anchor` 1.5.6). Anchor IDLs carry no display metadata, so these show what Codama displays for a program that has not added any.
